## 🚀 Featured Projects

### [URL Shortener](https://github.com/tsetan13821/URLShortener)
A production-style URL shortener built with **Spring Boot, PostgreSQL and Redis**.
- Redis caching for redirects, with automatic fallback to PostgreSQL if Redis goes down
- Per-IP rate limiting and click analytics, batched from Redis into PostgreSQL
- Non-guessable short codes, input validation, and Flyway-managed schema
- Dockerized, tested in CI with GitHub Actions, and deployed on Render

### [Smart Exam Surveillance](https://github.com/tsetan13821/smart-exam-surveillance)
A real-time exam proctoring system with a **FastAPI** backend and a React console.
- Verifies student identity with face recognition and flags photo spoofing
- Tracks head pose and gaze, and detects phones and other devices
- Pushes live alerts to proctors and generates per-session reports
